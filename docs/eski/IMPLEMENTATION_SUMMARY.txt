🚀 COMO USAR
═══════════════════════════════════════════════════════════════════════════════

PASSO 1: Ativar em config.py
──────────────────────────────
ENABLE_CONE_DETECTION = True

PASSO 2: (Opcional) Ajustar cores se necessário
─────────────────────────────────────────────────
Se cones não forem laranja padrão:

    CONE_HSV_LOWER = (0, 80, 80)      # Ajuste conforme cor
    CONE_HSV_UPPER = (15, 255, 255)

PASSO 3: (Opcional) Ativar debug
─────────────────────────────────
Para ver cones detectados:

    CONE_DEBUG_DRAW = True

PASSO 4: Executar
──────────────────
python dual_main.py --video seu_video.mp4

Agora a linha é detectada dinamicamente!

⚠️ NOTAS IMPORTANTES
═══════════════════════════════════════════════════════════════════════════════

1. Se ENABLE_CONE_DETECTION = False
   → Sistema volta ao modo manual (linhas estáticas)
   → Config anterior (DUAL_*_LINE_Y) é ignorada

2. Se cones não forem encontrados em um frame
   → Usa linha anterior (fallback automático)
   → Não quebra o processamento

3. Sistema detecta até 2 cones por frame
   → Extremo esquerdo + extremo direito
   → Se 3+ cones, usa apenas os dois extremos
   → Se 0-1 cones, usa linha anterior

4. Cores HSV variam com iluminação
   → Teste em diferentes lighting conditions
   → Use exemplo_cone_detection.py para calibrar

5. Suavização pode causar lag em movimento rápido
   → Reduzir CONE_LINE_SMOOTHING_ALPHA se necessário
