 SISTEMA DE LINHA DINÂMICA ANCORADA NOS CONES
 Implementação Completa
═══════════════════════════════════════════════════════════════════════════════

OBJETIVO ALCANÇADO ✓
═══════════════════════════════════════════════════════════════════════════════

A linha que os corredores precisam cruzar agora está DINAMICAMENTE ANCORADA
na BASE dos cones (onde tocam o chão) em ambas as câmeras.

Benefícios:
───────────
✓ Câmera pode se mover que a linha permanece fixa nos cones
✓ Detecção automática — sem necessidade de calibração manual
✓ Suavização contra tremidas de câmera
✓ Adapta-se a diferentes posições dos cones
✓ Compatível com sistema existente


COMO FUNCIONA
═══════════════════════════════════════════════════════════════════════════════

1. DETECTA OS CONES
   └─ Em cada frame, procura por cones laranja/vermelho
   └─ Encontra o cone mais à esquerda e mais à direita

2. ENCONTRA A BASE
   └─ Identifica o ponto mais baixo de cada cone (onde toca o chão)
   └─ Não usa o centro — usa a base!

3. CRIA A LINHA
   └─ Desenha linha entre a base do cone esquerdo e direito
   └─ A linha muda conforme cones se movem

4. SUAVIZA
   └─ Filtra tremidas/oscilações de câmera
   └─ Mantém movimento natural

PERSONALIZAÇÕES
═══════════════════════════════════════════════════════════════════════════════

Se seus cones NÃO forem laranja padrão, ajuste em config.py:

Para CONES AMARELOS:
  CONE_HSV_LOWER = (15, 50, 50)
  CONE_HSV_UPPER = (35, 255, 255)

Para CONES VERMELHOS:
  CONE_HSV_LOWER = (170, 80, 80)
  CONE_HSV_UPPER = (180, 255, 255)

Para DEBUG (ver cones na tela):
  CONE_DEBUG_DRAW = True

Quando debug estiver ON, você verá:
  🔵 Círculos azuis = centros dos cones
  🔴 Círculos vermelhos = BASES (onde detecta a linha)
  🟢 Linha verde = linha dinâmica criada

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ "Não detecta nenhum cone"
✅ Solução 1: Ativar CONE_DEBUG_DRAW = True e ver se algo é detectado
✅ Solução 2: Ajustar CONE_HSV_LOWER/UPPER conforme cor real
✅ Solução 3: Reduzir CONE_MIN_AREA_PX para detectar menores

❌ "Detecta muitos falsos positivos"
✅ Solução 1: Aumentar CONE_MIN_CIRCULARITY = 0.6
✅ Solução 2: Reduzir CONE_MAX_AREA_PX = 30000
✅ Solução 3: Afunilar faixa HSV

❌ "Linha fica tremendo"
✅ Solução: Aumentar CONE_LINE_SMOOTHING_ALPHA = 0.85

❌ "Linha demora para atualizar após câmera se mover"
✅ Solução: Reduzir CONE_LINE_SMOOTHING_ALPHA = 0.5

ARQUITETURA
═══════════════════════════════════════════════════════════════════════════════

    ├─ Inicializa ConeLineAdapter (para cada câmera)
    │  ├─ Cria ConeDetector

    │
    ├─ Loop principal:
    │  ├─ Lê frame
    │  ├─ Chama adapter.detect_and_create_line(frame)

    │  │  ├─ tracker.update(cone_line) → suavizado ConeLine

    │  ├─ Usa PerspectiveLine para detecção de cruzamento
    │  └─ (resto do processamento igual)
    │
    └─ Desenha (se CONE_DEBUG_DRAW = True):
       ├─ adapter.draw_debug_cones()
       └─ círculos azuis/vermelhos

PARÂMETROS IMPORTANTES
═══════════════════════════════════════════════════════════════════════════════

config.py:

ENABLE_CONE_DETECTION = True
  └─ Master switch: ativa/desativa tudo

CONE_HSV_LOWER / CONE_HSV_UPPER
  └─ Faixa de cor dos cones (HSV)
  └─ Ajuste conforme iluminação

CONE_MIN_AREA_PX = 200
  └─ Mínimo de pixels para ser um cone
  └─ Reduzir = mais sensível | Aumentar = menos ruído

CONE_MAX_AREA_PX = 50000
  └─ Máximo de pixels
  └─ Bloqueia grandes falsos positivos

CONE_MIN_CIRCULARITY = 0.4
  └─ Quanto circular o contorno deve ser (0-1)
  └─ Aumentar = menos falsos positivos

CONE_LINE_SMOOTHING_ALPHA = 0.7
  └─ Suavização temporal (0-1)
  └─ 0 = muito suave | 1 = sem suavização

CONE_DEBUG_DRAW = True/False
  └─ Desenha cones na saída
  └─ Use True para testar, False para produção


FLUXO COMPLETO

  cones1 = adapter1.detect_and_create_line(frame1)
  cones2 = adapter2.detect_and_create_line(frame2)
  
↓

Usa linhas detectadas como:
  evaluator.start_line_profile = cone_line (se encontrou)
  evaluator.far_line_profile = cone_line (se encontrou)

↓

Resto do sistema usa linhas normalmente
  (y_at(x) para interpolação)

↓

Saída: video com linhas dinâmicas ancoradas nos cones!
